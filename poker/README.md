# 夢回德州：卡通賭神之路（Dream Poker）

現代賭場 × 美式黃皮膚卡通風的德州撲克冒險遊戲。網頁版先行，純 HTML/CSS/JavaScript，**不需要建置、不需要伺服器、不需要任何素材檔**（角色、場景、籌碼、音樂全部由程式即時繪製／合成）。

## 怎麼玩

- 直接用瀏覽器開啟 `poker/index.html` 即可（雙擊檔案也能跑）。
- 鍵盤：`F` 棄牌、`C`／空白鍵 過牌或跟注、`R` 加注、`A` 全下、`Esc` 暫停選單。

## 功能對照

| 需求 | 實作 |
|---|---|
| 開新遊戲 | 輸入名字、選 3 種主角外觀、選難度、選存檔位置 |
| 讀取紀錄（20 格） | 20 個存檔格，顯示關卡、難度、籌碼、勝場、遊玩時間；可刪除；遊戲中每打完一手自動存檔，也可在暫停選單手動存到任意格 |
| 設定 | 畫質（低／中／高：控制動畫、陰影、背景角色）、螢幕解析度（自動／960×540～1920×1080）、全螢幕、音質（22k／44.1k／48k＋混響）、主音量／音樂／音效、遊戲速度、勝率提示 |
| 自由模式 | 任選 10 個場景、從該關或全部角色中挑 1～5 位對手、難度、起始籌碼、盲注、升盲速度 |
| 真實規則 | 無限注德州撲克：按鈕位輪轉、大小盲（單挑時按鈕＝小盲）、最小加注規則、不足額全下不重開加注、主池／邊池、平分底池與零頭分配、攤牌順序 |
| 5 種難度 | 小嫩嫩、新手、普通玩家、老手、賭神 —— 再乘上關卡進度（越後面越強）與角色個人加成 |
| AI 多種玩法 | 8 種個性：石頭型、緊兇、鬆兇、跟注站、瘋子、狡猾慢打、亂打（小孩）、均衡型；會算勝率、底池賠率、位置、對手範圍，高手會記住你的詐唬習慣 |
| 表情變化 | 8 種表情（平常、開心、得意、擔心、生氣、驚嚇、難過、思考）；**低手的表情會洩漏牌力（tell）**，高手會撲克臉甚至反向演戲 |
| 台詞 | `js/dialogue.js` 語詞庫，40 位角色 × 11 種事件，方便後製修改 |
| 籌碼花色 | 參考拉斯維加斯標準面額色（白 1、紅 5、綠 25、黑 100、紫 500、黃 1K、橘 5K、藍 25K、金 100K）＋卡通邊緣色塊 |
| 資產多寡呈現 | 籌碼堆依金額與盲注自動混搭面額，越有錢越多疊、越高、面額越大 |
| 10 關劇情 | 見 `js/levels.js`；第 4 關分三站、第 5 關分四個章節（街頭→吧台→錢莊→老大） |

## 檔案結構

```
poker/
├─ index.html        畫面骨架（標題、新遊戲、存讀檔、設定、自由模式、故事、牌桌）
├─ css/style.css     現代賭場 × 卡通粗框風格
└─ js/
   ├─ cards.js       牌組、7 張取 5 牌型判定、Monte Carlo 勝率
   ├─ engine.js      德州撲克規則引擎（狀態機，與畫面無關，可單獨測試）
   ├─ ai.js          AI 決策、難度、個性、表情 tell
   ├─ characters.js  角色外觀與個性（改這裡就能換人設）
   ├─ levels.js      10 關設定、劇情文字、盲注表、序章與結局
   ├─ dialogue.js    ★ 台詞語詞庫（後製修改請改這個檔）
   ├─ avatar.js      卡通頭像 SVG 產生器
   ├─ scenes.js      10 個場景背景 SVG
   ├─ chips.js       籌碼與籌碼堆
   ├─ audio.js       Web Audio 合成音效與每關背景音樂
   ├─ storage.js     20 格存檔與設定
   └─ main.js        畫面流程與牌局控制
```

## 修改台詞

打開 `js/dialogue.js`，每個角色一個區塊：

```js
k_ryu: {
  greet: ['我是最強的！哈哈哈！'],
  allin: ['全下！因為全下聽起來最帥！', '龍之全下！'],
  ...
},
```

事件：`greet` 打招呼、`fold` 棄牌、`check` 過牌、`call` 跟注、`raise` 加注、`allin` 全下、`win` 贏池、`lose` 輸大池、`bust` 被淘汰、`taunt` 嗆聲、`bluff` 沒攤牌就收池。
角色沒寫的事件會自動用「個性通用」或「全體通用」台詞補上。`{name}` 會換成玩家名字。

## 之後做成 Windows 安裝版

程式完全不依賴伺服器，可直接包裝：

1. **Electron**（最簡單）：把 `poker/` 放進 Electron 專案，`BrowserWindow.loadFile('poker/index.html')`，用 electron-builder 產生 `.exe` 安裝檔。
2. **Tauri**（檔案小很多，約 5～10 MB）：同樣以 `poker/` 為前端目錄。
3. 存檔目前在瀏覽器 `localStorage`；包成桌面版時只要改 `js/storage.js` 的 `read`／`write` 兩個函式，換成寫入使用者文件夾即可。
4. 字型目前從 Google Fonts 載入，離線時會退回系統字型（微軟正黑體）；正式版建議把字型檔一起打包。

## 角色與版權注意事項

- 第 6 關的小鎮角色是**致敬／惡搞的原創角色**（Homie、Bartie、Margie、Moey），刻意不使用官方角色名稱與招牌台詞。若要商業上架，建議再把外型做得更原創（例如髮型、服裝配色），避免與《辛普森家庭》的商標角色過於相近。
- 第 2 關以職稱（總統、副總統、行政院長、在野黨主席）呈現，不指名特定人物；第 7 關的川普、赫格賽斯為政治諷刺卡通，台詞走輕鬆路線。上架平台若對真實政治人物有規範，可在 `characters.js` 改成職稱或虛構名字。
- 第 8、9 關的宗教人物採溫和、友善的幽默方向，避免冒犯；如需調整，同樣只要改 `dialogue.js`。

## 開發測試

規則引擎與 AI 可在 Node 直接跑（不需瀏覽器），例如用 AI 自我對戰數千手檢查籌碼守恆、邊池與牌型判定。
